# 智策工作台界面改版

2026-11-02。入口仍是 `http://127.0.0.1:8793/`。本次将11块纵向堆叠的实验改为侧栏导航，主页面专注原定四Agent的物流决策。

## 使用顺序

1. 在“协作工作台”选择城市、月日、快递员、决策目标、预算与运行方式。“回放设置”可调整开始时刻和时长。
2. 点击“开始四Agent协作”，页面定位到协作流程。四节点依次显示待命、执行中、完成、拒绝或失败，箭头表示任务交接。
3. 点击任一节点，查看该角色输入、处理职责与已验证输出。展开过程记录可查看任务提交和后台执行事件。
4. 结果区查看当前待处理数、建议关注数、资源支出、独立复核状态；关注任务默认展示5笔，可展开全部。右侧比较四种策略的事后规则效用。
5. 下载协作证据，或进入“证据与说明”检查完整角色记录、原始SQL和回放。已有运行编号可载入，条件会同步恢复。

“经营分析”保留Olist问题理解、条件查询与商家排查；“算法实验”保留预测、预算、反馈和模拟策略对照。早期角色实验收在经营分析中的折叠区。

## 状态与证据

新增 `POST /api/four-agents/stream` 返回逐行JSON。角色开始事件在实际模型或工具调用前发出；完成事件只在输出通过程序校验后发出；最后返回持久化并校验的完整记录。原有一次性请求接口继续可用。

界面不通过定时器轮流点亮节点。断开连接或未收到最终记录时，不发布完整建议；不会把断线解释为服务端任务已经取消。历史记录会明确标注为历史运行，不将其动画包装成实时协作。

真实模型与仅工具模式分别显示实际调用次数。全日超窗比例、策略回放成绩属于事后核对，资源费用与关注行动为模拟。没有增加真实物流干预或跨数据源关联能力。

## 实现与验证

页面代码在 `agent_demo/index.html`、`workspace.css`、`workspace.js`；既有Olist与算法按钮逻辑保留于 `app.js`。后台进度回调位于 `zhice/four_agents.py`，流式接口位于 `zhice/agent_server.py`。

本轮111项自动测试通过，新增测试覆盖角色调用前的开始事件、非法输出不产生完成事件，以及HTTP进度流和持久化结果一致。日志：`reports/frontend-redesign-tests.log`。浏览器已验证导航、真实模型运行、节点详情、任务展开、证据下载、既有Olist查询和预算边界；汇总见 `reports/frontend-redesign-acceptance.json`。

改版前的一次性页面生成器和临时备份已在工作区清理时移除；当前页面直接维护 `agent_demo/` 下的源码。既有 `four-agent-acceptance.json` 是上一版本的历史验收，其代码哈希不能直接作为本轮源代码哈希；本次报告单独记录，不改写旧版证据。
