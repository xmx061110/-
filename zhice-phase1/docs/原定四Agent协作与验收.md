# 原定四Agent协作与验收

2026-11-02。本次完成LaDe真实揽收历史场景的本地受控协作：用户确认范围，总控传递目标，经营分析读取当时快照，优化决策调用预算工具并选择反馈策略，方案评审检查后输出建议。原来的第⑥部分保留为历史排查实验；新入口是第⑪部分。

## 怎样使用

服务当前在 `http://127.0.0.1:8793/`。新版使用侧栏“协作工作台”：选择城市、月日、快递员、目标、预算及运行方式，点击“开始四Agent协作”。开始时刻与时长可在“回放设置”中调整。范围改变会清空旧结果；目录加载和协作运行期间会锁定相关操作。原第⑩、⑪部分已整合到同一工作台，原始记录放到“证据与说明”。

“真实模型协作”依次调用同一模型4次，分别扮演四个角色；“仅工具演练”由程序演练流程，不调用模型。模型不可用时明确报错，不把工具演练冒充模型成功。完成后可看角色卡片、当前选单与事后回放，下载完整运行证据。

新版节点状态由 `/api/four-agents/stream` 的后台实际执行事件更新，没有定时假进度；点击节点可查看输入、处理和输出。历史记录载入会明确标注“已载入历史记录”，不会重播成刚刚发生的执行。

重新启动可双击工作区根目录 `启动工作台.cmd`（默认8793端口），或在本项目目录运行：

```powershell
python -m zhice.agent_school --port 8793 --open
```

启动器自动使用已授权的本机团队配置；没有配置时再提示输入密钥，输入不显示。本项目目录内直接运行命令时，需先关闭占用同端口的旧服务。只演练工具可用 `python -m zhice.agent_server --port 8793 --open`，并明确选择“仅工具演练”。依赖沿用 `requirements.txt`，不新增框架。

本机已授权的团队配置现保存于 `config/团队模型配置.json`，启动时会自动读取，环境变量优先。清理旧分享包不会影响配置。也可运行：

```powershell
python -m work.four_agent_acceptance --serve --port 8793
```

## 四个角色各做什么

| 角色 | 输入与职责 | 程序约束 |
|---|---|---|
| 总控Agent | 已确认的LaDe范围和目标，生成固定任务步骤 | 不可改数据源、目标或步骤 |
| 经营分析Agent | 截至开始时刻的已接单、已完成、待处理、超窗和临近截止任务 | 关注点由事实校验，不可编造延误原因 |
| 优化决策Agent | 当前快照、整数预算工具的初始方案，选择四种反馈策略之一 | 任务和费用由工具给出；模型不得修改数字；禁止按事后成绩挑策略 |
| 方案评审Agent | 确认条件、初始方案、独立复核结论及限制 | 可拒绝；程序发现越界、超支、重复或假任务时不会发布方案 |

这是固定流程的结构化协作，分析枚举和目标传递受到严格约束；尚不是开放式任务规划，也未让四个模型自行协商。目标“减少频繁变动”通常选稳定重排，但不保证每个样本都优于即时重排。

## 数据、时刻和预算怎样复核

起点只使用所选快递员当日有效完整任务，`accept_s <= 起点`；`finish_s <= 起点`可判定当时已完成，其余属于待处理。真实完成时间只在本地用于历史状态重建，不传给决策模型。模型输入没有未来接单、未来完成时刻、全日延迟率或回放成绩。年份未知；内部相对秒数与SQL参考年不代表实际年份。

规范化 `tasks` 查询与 `raw_pickup` 原始字符串独立解析查询逐行对账。模型可见快照不含未来结果；每次最多取当前队列按接单时刻和任务行号排序的前100笔，不声称覆盖整日所有任务的最优调度。初始方案通过精确整数预算工具计算；资源费用为固定哈希生成的1—10点，不是真实物流成本。规则优先级不是延误概率。

模型选定策略并评审后才进行历史回放。后续每5分钟的状态与预算调整由确定性算法完成，未每轮重新调用模型。模拟关注行动不改写真实完成时刻，每轮最多一次行动；历史真实延迟率只能作为事实复核，不能解释为该方案的效果。

## 查看记录和SQL

运行记录保存于独立 `data/workflow-runs.sqlite`，包括确认条件、角色输入输出、工具输出、失败记录及结果指纹；不写入密钥或认证标头。事件有顺序和SHA-256前后链接，最终结果摘要也被链接。此机制用于本地一致性检查，没有外部签名，不能抵御同时重写整个数据库。

下载JSON后，`result.snapshot_evidence.standalone_raw_reference` 是可直接在LaDe SQLite库中执行的起点原始查询，无需注册Python函数；其结果行数应等于 `result.snapshot.accepted_count`。当前未完成数为这些行中 `finish_s > result.snapshot.as_of_s` 的数量。`result.retrospective_metrics.sql.standalone_raw_reference` 可复算全日真实指标。

接口：`POST /api/four-agents`；`GET /api/four-agents/runs/<运行编号>`；`GET /api/four-agents/config` 仅返回模型是否配置、模型名和角色。数据库读取与记录读取都会重新检查，不以页面显示的“通过”代替数据核对。

主要代码：`zhice/four_agents.py`、`zhice/agent_server.py`、`agent_demo/app.js`。复用预算求解、LaDe查询及回放器。
