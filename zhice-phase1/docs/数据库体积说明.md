# 数据库为什么大

当前LaDe数据库5.30GB，Olist数据库327.5MB。两者都是未压缩的SQLite文件，数据库分享包约1.94GB是压缩后的体积。

| LaDe内容 | 体积（十进制GB） |
|---|---:|
|原始揽收与派送明细|1.90|
|轨迹、路网与汇总归档|1.52|
|规范任务及范围目录|0.78|
|查询索引|1.10|

LaDe规范任务表保留10,650,808行任务；结构化原始表合计21,073,821行，其中包含8,888,199条轨迹记录。原始表用于来源与独立SQL复核，规范任务表用于指标和算法，因此部分业务信息存在两种表达。

轨迹、路网与汇总归档约1.52GB，当前选单不读取它们；保留它们是为了完整来源留档和后续扩展。查询索引约1.10GB，换取筛选和对账速度。

LaDe空闲页数量：0；Olist空闲页数量：0。本次没有压缩、抽样或删除表，只清理工作区重复副本。

详细逐表与逐索引字节数见 `reports/数据库体积分析.json`。
