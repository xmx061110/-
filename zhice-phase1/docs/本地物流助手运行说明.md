# 智策本地物流助手

2026-11-02更新：当前入口为上一级 `启动工作台.cmd`，默认8793端口；团队配置已迁至 `config/团队模型配置.json`，原始说明中的旧启动文件由这一统一入口替代。当前四角色与可视化工作台使用方法见 [前端工作台改版说明](前端工作台改版说明.md)。下文保留单Agent初版的历史说明。

## 目前能做什么

在项目根目录双击 `打开智策物流助手.cmd`，浏览器会打开 `http://127.0.0.1:8788`。服务只监听本机；窗口关闭后服务停止。支持选择月份、商品类别、商家，查询 SQLite 数据并独立从原始表复核；可以查看 SQL 和下载完整证据。地址被占用时，关闭占用程序或使用 `python -m zhice.agent_server --port 8789 --open`。

这是单智能体的本地原型。模型用来理解问题并提取条件；用户必须核对模型提取的条件，再点击查询。程序不会把模型自由生成的数字作为查询结果。当前支持单范围指标，不支持排行、趋势比较、预测和加急优化。历史数据和真实成本的限制见阶段一文档。

## 大模型接入

2026-10-29 已使用学校提供的 deepseek-v4-flash 模型，通过真实接口测试了月份、商品类别、商家三个问题，均正确提取条件并通过数据库独立复核；缺少真实利润的数据问题返回不支持。双击项目根目录 `打开智策物流助手_学校模型.cmd`，在窗口中输入 API 密钥（输入时不显示），程序仅将其保存在当前进程的环境中。关闭窗口后需重新输入。原来的启动文件不自动接入模型。网页交互仍需用户在本机确认；模型可能理解错问题，查询前要核对筛选范围。

使用其他模型时，需要支持 OpenAI Chat Completions 格式和工具调用的服务，并在启动前配置下面三个环境变量。兼容性必须实际测试，不能仅凭名称认定。

在 PowerShell 中（替换为实际服务信息，密钥不要发给别人或写入代码）：

```powershell
$env:ZHICE_MODEL_URL = 'https://实际服务地址/v1/chat/completions'
$env:ZHICE_MODEL_NAME = '实际模型编号'
$env:ZHICE_MODEL_KEY = '自己的密钥'
cd 'C:\Users\32257\Desktop\华为ict\zhice-phase1'
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m zhice.agent_server --open
```

如果有本地兼容服务，可使用本机 HTTP 地址和服务所需的占位 key。模型地址必须是完整的 `/chat/completions` 接口，不是管理页面。在线服务会收到用户提出的问题，请自行确认数据使用条件；查询结果由本地计算，不会发回模型。页面需逐项核对筛选范围，原始表复核并不能保证模型理解问题正确。
