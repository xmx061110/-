# 智策第二阶段：单智能体原型

## GitHub 调研和选择

- [华为云 AgentArts Python SDK](https://github.com/huaweicloud/agentarts-sdk-python)：官方 SDK，Apache-2.0；包括运行时封装和示例，是后续接入 AgentArts 的优先参考。当前尚未安装 SDK 或连接云端。
- [text-to-sql-assistant](https://github.com/YenuraK/text-to-sql-assistant)：MIT；参考自然语言、只读查询和可见 SQL 的设计。其通用 SQL 生成方式没有智策特有的订单、商品和评分口径，不能直接作为正确性保证。
- [NL2SQL_Bot](https://github.com/ArtysicistZ/NL2SQL_Bot)：展示聊天、SQL、图表的界面思路；其 MySQL 示例和应用栈需改造才能使用我们的数据库。

这里未复制上述项目源码。针对第一阶段的业务口径自行编写工具调用原型。华为云[插件说明](https://support.huaweicloud.com/lowcode-agentarts/agentarts_05_0123.html)支持自定义 API 类型插件；实际接入需部署可被平台访问的服务和配置鉴权，本项目尚未完成这些步骤。

## 已实现什么

单次问题经模型选择工具及参数，固定工具调用阶段一 `verify_selection`，由 SQLite 分别计算和独立从原始表复核。数字由程序直接渲染，模型的自由文本不会作为指标输出；可导出带两份 SQL 的 JSON。只支持单个范围的月份、类别、商家交叉筛选。无有效分母显示无法计算，复核失败停止输出。

模型仍可能误解问题、漏掉筛选、选择不正确的代码或把不支持的问题当作单范围查询；因此输出显示实际筛选条件，必须由使用者核对。独立复核只能验证该筛选条件下的计算，不能证明模型正确理解了问题，当前没有实现端到端的语义正确性保证。

本地模型接口采用 OpenAI Chat Completions 风格的工具调用协议；**不代表所有华为云模型都兼容**。必须使用明确支持该协议及工具调用的服务，或后续适配 AgentArts 原生接口。通过环境变量配置，不要将密钥提交或发送给他人。请求会将问题发送给配置的模型服务；数据查询在本机执行，代码不会将查询结果发给模型。

## 运行

在 `zhice-phase1` 目录的 PowerShell 中设置（值由实际服务提供商提供，URL 必须是完整聊天补全接口）：

```powershell
$env:ZHICE_MODEL_URL = 'https://实际服务地址/chat/completions'
$env:ZHICE_MODEL_KEY = '自己的密钥'
$env:ZHICE_MODEL_NAME = '实际模型名称'
python -m zhice.agent '2018-01 的订单量和配送延迟率是多少？' --evidence agent-evidence.json
```

证据文件中的 `filters` 为实际执行条件，`program` 和 `reference` 为两条路径的结果，`sql` 含可执行的原始表复核 SQL。类别使用原始葡语代码；商家使用完整 seller_id。筛选范围不存在时返回空集，而不是编造数字。

## 验证和尚未完成

运行 `python -m unittest discover -s tests -p test_agent.py -v`。测试覆盖模拟模型工具调用、错误参数、复核失败及真实数据库的三种筛选；模拟模型不等于真实模型测试。当前未配置模型账号或 AgentArts 云端环境，**尚未进行真实大模型调用、云端部署、三道自然语言问题的端到端验收**。对比、排行、趋势、预测、原因分析和利润计算均未实现；不要将本原型作为完整的第二阶段验收结果。

下一步：准备一个支持工具调用的模型访问方式，选定三个覆盖月份、类别、商家的真实提问，记录模型提取参数并逐一与用户意图和 SQL 结果核对；再按 AgentArts 实际环境选 SDK 或 API 插件，完成云上联调。跨商家或类别的订单数可能重叠，销售额仅统计已送达商品、不含运费；数据中缺少真实成本。
