# 单智能体阶段验收报告

验收日期：2026-11-01。对象是本地 Olist 物流分析原型，不含华为云部署。

后续已扩充为200题真实模型验收，并增加历史商家延迟排查工具。最新结果见 `reports/200题真实模型验收报告.md`，以下10题结果保留为此前小样本记录。

## 本次结果

- 真实数据库查询与原始表独立 SQL 对照：10/10 个筛选案例通过，每例 21 项指标一致，共 210 项对照。覆盖全部订单、两个不同月份、两个类别、一个商家、两项及三项组合，以及空结果。三项组合和无匹配月份均为零订单，零分母比率为 NULL。无匹配月份通过底层工具验证，网页目录只允许选择数据集中存在的值。
- 项目自动测试：36/36 通过，包括接口实际请求、取消订单、重复支付、商品多行、空分母、篡改金额检测等；测试中的模型决策使用模拟响应，不代表真实模型准确率。
- 本次真实大模型测试：北理工 BIT MaaS 的 `deepseek-v4-flash` 共 10/10 题达到预设结果。其中 5 题识别月份、类别、商家或组合条件，5 题对相对时间、比较、排行、利润及原因请求返回限制提示。5 道可查询问题分别继续执行数据库查询，每题 21/21 项与原始表 SQL 一致。该数字仅代表本次固定的 10 道题，不能推断整体准确率；模型随机性、其他措辞以及不同模型均可能产生不同结果。

结果和每个筛选的两份可单独执行的 SQL 见 `reports/单智能体验收结果.json`。数据库对照是两条实现路径的一致性检查，并不是对所有可能筛选或所有业务规则的数学证明。模型提取条件仍须由用户在界面上确认，SQL 复核不能证明模型理解正确。

## 本次修复

修复查询接口把 `false`、数字零或空数组等错误筛选值当成未筛选条件的问题，防止无意扩大查询范围；现在返回 HTTP 400。新增对应接口回归测试。

## 复现

在项目根目录使用 Python 3.11 或更新版本：

```powershell
python -m unittest discover -s tests -v
python -m work.phase2_acceptance
```

执行真实模型测试前，参照 `docs/本地物流助手运行说明.md` 配置模型环境变量，然后运行 `python -m work.phase2_acceptance --real-model`。该选项会向模型提供商发送 10 条测试问题，可能产生费用；不要把密钥写进代码或报告。结果记录于同一个 JSON 文件，不会记录密钥。运行前如需保留本次结果，请先另存结果文件。真实模型用例检查条件是否按预期提取、超出支持范围时是否拒绝；失败时会记录对应问题，不能以数据库通过率代替模型通过率。

## 阶段边界与后续

当前仍是本地单智能体原型，不支持自动比较、排名、趋势、真实成本或因果判断。本次模型测试直接调用应用的模型解析与查询函数，未重新开展浏览器人工操作验收；网页中仍须由用户确认筛选条件。下一步可扩充不同措辞、边界条件和浏览器操作测试，然后围绕配送延迟诊断设计多智能体；华为云接入单独验收。
